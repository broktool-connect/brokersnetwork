# Sitio web de Brokers Network

Sitio estático (HTML, CSS y JS sin dependencias) de www.brokersnetwork.mx, publicado con GitHub Pages.

## Páginas
- `index.html` — Inicio: portada, quiénes somos, cifras, qué necesitas y contacto.
- `servicios.html` — Nuestros servicios: propietarios, requisitos (compartir por WhatsApp), asesores por zona, crédito, renta y más servicios.
- `como-trabajamos.html` — Para asesores: operaciones compartidas y modelo de comisiones.
- `registro.html` — Quiero afiliarme: formulario de 3 pasos que abre WhatsApp (+52 55 2061 2236) con el resumen de las respuestas.

## Cómo editar
1. Cambia el archivo en GitHub (lápiz ✏️) o en tu computadora.
2. Guarda con "Commit changes". GitHub Pages publica solo en 1 a 2 minutos.

## Dominio
- `CNAME` contiene `www.brokersnetwork.mx`.
- DNS: `www` → CNAME a `broktool-connect.github.io`; dominio raíz → registros A de GitHub Pages
